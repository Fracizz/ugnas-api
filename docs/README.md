# Documentation

The repository uses English as its default documentation language. Chinese
translations and examples are available from the [Chinese README](../README.zh-CN.md).

- [English usage guide](usage.en.md): installation, configuration, Python API, CLI, file
  transfers, sharing, and troubleshooting notes.
- [中文使用指南](usage.md): same topics with Chinese examples.
- [English login and file-list API](api-login-filelist.en.md): protocol observations for
  login, authentication headers, and directory listing.
- [中文登录与文件列表 API](api-login-filelist.md): 中文协议记录。
- [English download and sharing API](api-login-download-share.en.md): protocol details
  for downloads, shares, direct URLs, and storage queries.
- [中文下载与分享 API](api-login-download-share.md): 中文协议记录。

The protocol documents describe an undocumented device interface. Verify
requests against the firmware version running on your own NAS and never
publish credentials, cookies, tokens, captures, or one-shot URLs.
